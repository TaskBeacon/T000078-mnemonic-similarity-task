# Task Plot Brief

Title: Mnemonic Similarity Task

Construct: episodic memory / pattern separation / hippocampal function

## Participant-Visible Flow

- The task has an incidental study phase followed immediately by a surprise recognition test.
- Every object is centered on a white screen for 2.0 s, followed by a blank white 0.5-s ISI.
- Study prompt: `INDOOR OR OUTDOOR?` with `V INDOOR · N OUTDOOR`.
- Test prompt: `OLD, SIMILAR, OR NEW?` with `V OLD · B SIMILAR · N NEW`.

## Representative Rows

1. Study: one everyday object, then blank ISI.
2. Target: exact repeat of a studied image, then blank ISI.
3. Lure: similar but nonidentical paired object, then blank ISI.
4. Foil: previously unseen object, then blank ISI.

## Reference Objects

- Study/target example: `assets/objects/078a.jpg` (wooden drawer cabinet).
- Lure pair: studied `assets/objects/100a.jpg` and tested `assets/objects/100b.jpg` (two different spray bottles); only the tested `100b` should appear in the lure-row participant screen.
- Foil example: `assets/objects/179a.jpg` (lock-pick tool set).

## Accuracy Notes

- Do not add feedback; the task provides none.
- Do not add fixation; each trial is object then blank ISI.
- Use equal screen sizes and keep the photographs undistorted.
- The target, lure, and foil test rows have identical timing and response options.
