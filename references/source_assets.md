# Source Assets

The 384 object photographs in `assets/objects/` and `assets/set1_bins.tsv` are an unmodified local copy of **Set 1** from Craig Stark's official MST distribution:

- Repository: https://github.com/celstark/MST
- Source files: `Set 1/001a.jpg` through `Set 1/192b.jpg`, plus `Set1 bins.txt`
- Retrieved: 2026-07-27
- Official repository purpose: to provide the stimuli and source code used to run the Mnemonic Similarity Task.

The task preserves the original pair IDs and `a`/`b` roles. No photograph is used as a placeholder.
